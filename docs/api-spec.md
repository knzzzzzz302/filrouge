# API Spec (extrait)

- POST `/api/auth/login`
- GET `/api/auth/me`

## Properties
- GET `/api/properties`
- POST `/api/properties`
- PATCH `/api/properties/:id`

## Clients
- GET `/api/clients`
- POST `/api/clients`

## Transactions
- GET `/api/transactions`
- POST `/api/transactions`
- PATCH `/api/transactions/:id/status`

## Analytics
