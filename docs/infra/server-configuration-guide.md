# Guide configuration serveurs

## Serveur AD
1. Installer Windows Server
2. Promouvoir en controleur de domaine `yplaza.local`
3. Configurer OU par agences et services
4. Appliquer GPO de securite postes

## Serveur applicatif
1. Installer Docker et runtime Node LTS
2. Deployer API et frontend
3. Configurer reverse proxy TLS

## Serveur DB
1. Installer PostgreSQL 16
2. Restreindre acces reseau par ACL
3. Configurer sauvegardes quotidiennes
